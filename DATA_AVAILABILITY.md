# Data Availability

The source cohort participant-level datasets are available only through the
respective CHARLS, ELSA, HRS, KLoSA, LASI, MHAS, and SHARE official data portals
or data access systems, subject to registration, application approval, and
data-use conditions. The authors downloaded approved de-identified cohort files,
then cleaned and harmonized the analysis files locally.

This public release does not contain raw source data, cleaned participant-level
cohort data, or derived participant-level analysis files. It contains analysis
code, harmonization metadata, aggregate non-identifying outputs, supplementary
workbooks, and figure-generation material.
